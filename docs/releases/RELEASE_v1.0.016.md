## 신규 기능

### 토큰 관리 및 자동 트리밍 (P1-02)
- 대화 히스토리 토큰 자동 관리
- 150,000 토큰 한도 초과 시 오래된 메시지 자동 제거
- `/tokens` 명령어 추가: 현재 토큰 사용량 확인

### API 재시도 로직 (P1-03)
- 네트워크 오류 및 서버 오류 시 자동 재시도 (최대 3회)
- 지수 백오프 + 지터 적용
- 재시도 가능 오류: 429, 500, 502, 503, 504

### 멀티라인 입력 (FSD v1.0.015)
- `/multiline` 명령어 추가
- `/end` 입력으로 멀티라인 입력 종료
