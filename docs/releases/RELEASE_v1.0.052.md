# RELEASE v1.0.052

## 릴리즈 정보
- **버전:** v1.0.052
- **배포일:** 2026-03-01

## 주요 변경 사항
- **로컬 프록시 서버 신규 구축:** GenAI, Claude, Gemini 3개의 서로 다른 API 엔드포인트를 OpenAI 호환 인터페이스 하나로 단일화하는 로컬 프록시 서버(Python FastAPI 기반)가 구축되었습니다.
- **다양한 클라이언트 연동 지원:** 프록시 서버를 통해 OpenCode 등 커스텀 Provider 등록 기능을 제공하는 도구와 연결하여 다양한 AI 모델들을 하나의 통일된 창구로 접근할 수 있게 확장되었습니다.
