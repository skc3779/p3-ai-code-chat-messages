# Release Notes v1.0.018

> **배포일**: 2026-01-25

## 🚀 주요 변경 사항

### 1. 실시간 파일 변경 감지 (File Watcher)
- **기능**: 프로젝트 내 파일이 수정되면 자동으로 감지하여 AI 컨텍스트를 갱신합니다.
- **명령어**:
  - `/watch <pattern>`: 파일 감시 시작 (예: `/watch *.py`)
  - `/unwatch <pattern>`: 파일 감시 중지
  - `/watch_list`: 현재 감시 중인 패턴 목록 확인
- **효과**: 수동으로 `/read` 명령어를 반복 입력할 필요가 없어져 개발 생산성이 향상됩니다.

## 🛠 기술적 상세
- `watchdog` 라이브러리를 도입하여 효율적인 파일 시스템 이벤트를 처리합니다.
- 별도 스레드에서 감시가 이루어져 채팅 흐름을 방해하지 않습니다.

---
**설치 필요**: `pip install watchdog`
