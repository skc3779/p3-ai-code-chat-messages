# Release Notes v1.0.019

> **배포일**: 2026-01-25  
> **관련 문서**: FSD_Streaming_Error_Handling_v1.0.019.md

## 🚀 주요 변경 사항

### 1. 스트리밍 안정성 강화
- **기능**: 네트워크 불안정 등으로 인해 AI 응답 스트리밍이 중단되더라도 프로그램이 종료되지 않도록 개선했습니다.
- **동작**:
  - 스트림 연결 끊김 발생 시 이를 감지하고 사용자에게 알림을 표시합니다.
  - 중단 시점까지 수신된 텍스트와 데이터는 보존되어 대화 히스토리에 안전하게 저장됩니다.
- **효과**: 긴 코드 생성 중 네트워크 오류가 발생해도 전체 내용을 잃지 않고 부분적인 복구가 가능합니다.

## 🛠 기술적 상세
- SSE(Server-Sent Events) 처리 루프에 예외 처리(`ChunkedEncodingError`, `ReadTimeout` 등)를 적용했습니다.
- 에러 발생 시 시스템 메시지를 자동으로 대화 내역에 추가하여 상황을 명확히 기록합니다.
