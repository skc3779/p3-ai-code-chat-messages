# RELEASE v1.0.027

## ✨ 주요 변경 사항

### 1. `/context` 명령어 개선
- 다중 파일 패턴 지원이 추가되었습니다.
- 이제 `[pattern1, pattern2]` 형식으로 여러 글로브 패턴을 한 번에 지정할 수 있습니다.
- **예시**:
    - `/context [src/*.py, docs/*.md] README 파일을 작성해줘`
    - `/context [*.py, *.html] 전체적인 구조를 설명해줘`
- 기존 단일 패턴 방식(`/context src/*.py 질문`)도 여전히 지원합니다.

### 2. 내부 리팩토링 (지난 버전 포함)
- `ResponseParser` 클래스 도입으로 파일 식별 및 저장 로직이 모듈화되었습니다.
- 중첩된 코드 블록 처리 로직이 개선되었습니다.
