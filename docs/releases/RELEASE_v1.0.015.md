## 주요 변경 사항
- **멀티라인 명령어 지원:** 여러 줄에 걸친 긴 프롬프트나 코드를 한 번에 입력하기 위한 `/multiline` 명령어가 추가되었습니다.
- **사용 방법:** `/multiline` 입력 후 여러 줄 내용 작성, 그 후 `/end` 입력 시 전체 내용이 AI에게 전송됩니다. 빈 줄을 2번 입력해도 멀티라인 모드가 종료됩니다.
