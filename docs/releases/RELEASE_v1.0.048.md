## 개요

v1.0.047에서 도입된 Gemini CLI 스타일의 전체 화면 인라인 UI 구현 과정에서 누락되었던 **프롬프트 잔상(Ghost Toolbar) 버그** 패치가 이루어졌습니다. 터미널이 한층 더 쾌적하고 깔끔한 UI를 제공하게 되었습니다.

---

## 버그 픽스 내역

### 1. 고스트 툴바(Ghost Toolbar) 클리어 기능 추가

새로운 커스텀 `Application` UI가 종료(`app.exit()`)되는 시점에, 터미널 윗줄에 사용자가 이전에 보았던 하단 상태바(회색 가로줄) 렌더링 내역이 버퍼로 찍히며 남아버리는 현상을 제거했습니다.

**적용 사항:**
- `erase_when_done=True` 옵션이 CLI 핸들러 레이아웃 코어에 활성화되었습니다. 
- 이제 명령어 사이클이 끝날 때, 제안 목록 상자와 상태 바가 증발하듯 깔끔하게 사라지며 직전 출력 텍스트들 바로 아래에 결과 데이터만 타일식으로 나타나게 됩니다.

### 2. "입력 프롬프트 텍스트 소멸" 현상 방지

위의 `erase_when_done` 설정은 사용자 본인이 직접 폼에 타이핑한 `> /clear` 라는 한 줄기 프롬프트 흔적마저 없애버리는 연쇄 작용이 있었습니다. 
이에 따라, Application이 종료된 직후에 `print()` 로 한 줄만을 예쁘게 터미널 버퍼에 구워내는 복원(`Restore`) 로직을 추가하여 마치 기존의 readline 콘솔과 완벽히 동일한 사용자 경험을 제공하게 되었습니다.
