## 주요 변경 사항
- **프롬프트 템플릿 시스템:** 하드코딩된 시스템 프롬프트를 제거하고, 상황에 맞게(코드 리뷰, 버그 수정 등) 최적화된 프롬프트 템플릿을 선택하여 사용할 수 있도록 개선되었습니다.
- **신규 템플릿 명령어:**
  - `/template <name>`: 특정 템플릿 적용
  - `/template_list`: 사용 가능한 템플릿 목록 조회
  - `/template_reset`: 기본 프롬프트로 복귀
