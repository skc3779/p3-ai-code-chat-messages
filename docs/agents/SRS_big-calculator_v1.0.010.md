## 1. 소개
### 1.1 목적
본 문서는 Python 3.10 이상을 사용하여 구현되는 **편리하고 직관적인 계산기 프로그램**의 요구사항을 정의한다. 사용자는 큰 디지털 화면과 큰 버튼을 통해 손쉽게 연산을 수행하고, 계산 내역을 확인·이전 단계로 되돌아갈 수 있다.
### 1.2 범위
- GUI 기반 데스크톱 애플리케이션
- 기본 사칙연산 및 소수점 연산 지원
- 계산 내역 표시 및 선택적 복원(Undo) 기능
- 화면·버튼 크기 조정에 대한 UI 요구사항 포함
### 1.3 정의, 약어 및 약자
| 용어 | 정의 |
|------|------|
| UI | User Interface, 사용자 인터페이스 |
| UX | User Experience, 사용자 경험 |
| Undo | 이전 연산 단계로 되돌리는 기능 |
| History | 사용자가 수행한 연산 기록 리스트 |
| 디지털 화면 | 계산 결과와 입력값을 표시하는 화면 영역 |

## 2. 전반적인 설명
### 2.1 제품 관점
계산기 프로그램은 독립 실행형 애플리케이션이며, 외부 시스템과의 연동은 필요하지 않다. Python 표준 라이브러리와 GUI 프레임워크(Tkinter 또는 PyQt 등)를 사용한다.
### 2.2 제품 기능
1. **큰 디지털 화면**
   - 현재 입력값 및 연산 결과를 크게 표시한다.
2. **큰 버튼**
   - 숫자·연산자·제어(클리어, 백스페이스 등) 버튼을 충분히 큰 크기로 제공하여 마우스·터치 조작이 용이하도록 한다.
3. **계산 내역 표시**
   - 화면 하단 또는 별도 패널에 수행된 연산을 순차적으로 나열한다.
4. **이전 계산 내역으로 복원(Undo)**
   - 사용자는 “Undo” 버튼을 눌러 직전 연산 상태로 되돌릴 수 있다.
5. **입력 오류 방지**
   - 잘못된 연산 입력(예: 연속된 연산자) 시 경고 메시지를 표시한다.
### 2.3 사용자 특성
- 일반 PC 사용자(학생, 사무직 등)
- 마우스·키보드 또는 터치스크린 환경에서 사용 가능
### 2.4 제약 사항
- Python 3.10 이상 필요
- 외부 라이브러리 사용 시 라이선스 호환성 검토 필요
### 2.5 가정 및 의존성
- 실행 환경에 Python 인터프리터와 선택된 GUI 프레임워크가 설치되어 있다.
- 파일 시스템 접근 권한은 필요하지 않다(계산 내역은 메모리 내에서 관리).

## 3. 구체적인 요구사항
### 3.1 기능 요구사항

| 번호 | 요구사항 | 설명 |
|------|----------|------|
| FR‑1 | 큰 디지털 화면 제공 | 화면 해상도에 관계없이 최소 200 px 높이의 텍스트 영역을 사용한다. |
| FR‑2 | 큰 버튼 제공 | 각 버튼 최소 60 px × 60 px 크기이며, 터치 입력을 고려한 여백을 둔다. |
| FR‑3 | 기본 연산 지원 | `+, -, *, /` 연산과 소수점(`.`) 입력을 지원한다. |
| FR‑4 | 연산 결과 실시간 표시 | 사용자가 입력할 때마다 현재 식과 결과를 화면에 실시간으로 업데이트한다. |
| FR‑5 | 계산 내역 기록 | 수행된 연산을 시간 순서대로 리스트에 저장하고 화면에 표시한다. |
| FR‑6 | Undo 기능 | “Undo” 버튼 클릭 시 가장 최근 연산을 취소하고 이전 상태를 복원한다. |
| FR‑7 | Clear 기능 | “C” 버튼 클릭 시 현재 입력과 결과를 초기화한다. |
| FR‑8 | 오류 처리 | 0으로 나누기 등 수학적 오류 발생 시 경고 메시지를 표시하고 연산을 중단한다. |
| FR‑9 | 키보드 입력 지원 | 숫자·연산자·Enter·Backspace 등 기본 키보드 입력을 허용한다. |
### 3.2 비기능 요구사항

| 번호 | 요구사항 | 설명 |
|------|----------|------|
| NFR‑1 | 성능 | 입력 → 화면 반영까지 지연시간 ≤ 100 ms |
| NFR‑2 | 호환성 | Windows 10 이상, macOS 12 이상, Linux 주요 배포판에서 실행 가능 |
| NFR‑3 | 유지보수성 | 코드 구조는 MVC(모델‑뷰‑컨트롤러) 패턴을 따르고, 함수·클래스당 최대 200줄로 제한한다. |
| NFR‑4 | 접근성 | 버튼에 충분한 대비 색상과 키보드 포커스를 제공한다. |
| NFR‑5 | 국제화 | 현재는 한국어 UI만 제공하되, 문자열은 별도 리소스 파일에 저장하여 다국어 확장이 가능하도록 설계한다. |
| NFR‑6 | 배포 | `pip` 패키지 형태 혹은 독립 실행 파일(.exe/.app) 형태로 배포한다. |
### 3.3 인터페이스 요구사항
#### 3.3.1 사용자 인터페이스
- **디지털 화면**: 상단 중앙에 위치, 폰트 크기 최소 24pt, 오른쪽 정렬.
- **버튼 레이아웃**: 4×5 그리드(숫자·연산자·제어) 형태, 각 버튼 라벨은 명확히 표시.
- **내역 패널**: 화면 하단에 스크롤 가능한 리스트, 각 항목은 “식 = 결과” 형식.
- **Undo/Redo**: “Undo” 버튼은 내역 패널 위에 배치하고, 색상은 강조색으로 표시.
#### 3.3.2 소프트웨어 인터페이스
- 내부적으로 `CalculatorModel` 클래스를 사용해 연산 로직을 구현하고, `CalculatorView`와 `CalculatorController`가 각각 UI와 이벤트를 담당한다.
#### 3.3.3 하드웨어 인터페이스
- 표준 입력 장치(키보드·마우스·터치스크린)만 사용한다.

## 4. 시스템 모델

```
+-------------------+        +-------------------+        +-------------------+
|   CalculatorView | <----> | CalculatorController| <----> | CalculatorModel   |
+-------------------+        +-------------------+        +-------------------+
        ^                               ^                         ^
        |                               |                         |
   UI 이벤트                         사용자 입력               연산 로직
```

- **Model**: 현재 식, 결과값, 내역 리스트 관리.
- **View**: 화면 구성 요소(디지털 화면, 버튼, 내역 패널) 렌더링.
- **Controller**: UI 이벤트를 받아 Model에 전달하고, Model 변경 시 View를 업데이트.
