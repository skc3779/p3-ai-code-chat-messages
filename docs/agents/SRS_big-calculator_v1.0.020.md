**작성일:** 2026-04-20  
**상태:** Draft

## 1. 소개

### 1.1 목적
본 문서는 데스크톱 환경에서 동작하는 공학용 계산기 애플리케이션의 기능/비기능 요구사항을 정의한다. 본 SRS는 개발, 테스트, 품질검토, 릴리스 판단의 기준 문서로 사용한다.

### 1.2 범위
본 제품은 다음 기능을 제공한다.
- 기본 연산: `+`, `-`, `×`, `÷`, `%`
- 공학 연산: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `log10`, `ln`, `sqrt`, `x^y`, `10^x`, `e^x`, `n!`
- 상수/기능: `π`, `e`, 부호변경(`+/-`), 괄호 우선순위, 소수점
- 메모리 기능: `MC`, `MR`, `M+`, `M-`, `MS`
- 내역 기능: 계산식/결과 히스토리, 선택 복원, Undo/Redo
- 각도 모드: Degree/Radian 전환

### 1.3 용어 및 약어
| 용어 | 정의 |
|---|---|
| Expression | 사용자가 입력한 계산식 |
| History | 수행된 계산식과 결과의 순차 기록 |
| DEG/RAD | 삼각함수 계산의 각도 단위 |
| Undo/Redo | 직전 상태 취소/재적용 |
| Domain Error | 정의역 위반으로 계산 불가한 오류 |

### 1.4 참조 문서
- Python 3.10+ 표준 문서  
- 선택 GUI 프레임워크 가이드(Tkinter/PyQt/PySide 계열)

## 2. 전반적 설명

### 2.1 제품 관점
본 시스템은 독립 실행형 GUI 애플리케이션이다. 외부 서버 연동 없이 로컬에서 계산을 수행한다.

### 2.2 사용자 특성
- 학생/연구자/엔지니어 등 수식 입력이 빈번한 사용자
- 마우스, 키보드, 터치 입력을 사용하는 일반 데스크톱 사용자

### 2.3 운영 환경
- OS: Windows 10+, macOS 12+, Linux 주요 배포판
- 런타임: Python 3.10 이상
- 해상도: 최소 1280×720 권장

### 2.4 제약사항
- 오프라인 단독 실행(클라우드 동기화 미포함)
- 계산 내역의 기본 저장 범위는 로컬 세션 기준
- 고정소수점/부동소수점 표시는 IEEE 754 한계를 따름

### 2.5 가정 및 의존성
- 실행 환경에 Python 및 GUI 프레임워크가 설치되어 있다.
- 사용자에게 기본 입력장치(키보드/마우스/터치)가 제공된다.

## 3. 구체적 요구사항

### 3.1 기능 요구사항

| ID | 요구사항 | 상세 |
|---|---|---|
| FR-001 | 숫자 및 기본 연산 입력 | `0~9`, `.`, `+`, `-`, `*`, `/`, `%` 입력을 지원한다. |
| FR-002 | 공학 함수 지원 | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `log10`, `ln`, `sqrt`, `x^y`, `10^x`, `e^x`, `n!`를 지원한다. |
| FR-003 | 괄호 및 연산 우선순위 | 중첩 괄호를 포함한 식 계산 시 수학적 우선순위를 보장한다. |
| FR-004 | 상수 입력 | `π`, `e` 상수를 단일 버튼 또는 키 입력으로 삽입 가능해야 한다. |
| FR-005 | 각도 모드 전환 | DEG/RAD 모드를 즉시 전환하고 이후 삼각함수 계산에 반영한다. |
| FR-006 | 실시간 표시 | 입력 중 현재 식을 화면에 표시하고, `=` 실행 시 결과를 표시한다. |
| FR-007 | 히스토리 조회 | 최근 계산식/결과를 시간순으로 표시하며 스크롤 조회를 지원한다. |
| FR-008 | 히스토리 복원 | 사용자가 히스토리 항목 선택 시 해당 식을 입력창으로 복원한다. |
| FR-009 | Undo/Redo | 입력 및 편집 상태를 단계적으로 취소/재적용한다. |
| FR-010 | 메모리 기능 | `MC`, `MR`, `M+`, `M-`, `MS`를 지원한다. |
| FR-011 | 오류 처리 | 0으로 나누기, 정의역 오류, 오버플로우 시 명확한 오류 메시지를 표시한다. |
| FR-012 | 키보드 단축 입력 | 숫자/연산자/Enter/Backspace/Esc/Ctrl+Z/Ctrl+Y를 지원한다. |
| FR-013 | 초기화 기능 | `C`는 전체 초기화, `CE`는 현재 입력만 초기화한다. |

### 3.2 비기능 요구사항

| ID | 요구사항 | 기준 |
|---|---|---|
| NFR-001 | 반응성 | 사용자 입력 후 화면 반영 평균 100ms 이내 |
| NFR-002 | 안정성 | 비정상 입력 시 앱이 종료되지 않고 오류를 복구 가능 상태로 유지 |
| NFR-003 | 정확성 | 일반 연산 및 공학 함수는 Python 수학 라이브러리 기준 허용 오차 내 결과를 제공 |
| NFR-004 | 사용성 | 주요 버튼 크기 최소 56×56px, 표시 폰트 최소 22pt |
| NFR-005 | 접근성 | 키보드만으로 주요 기능 접근 가능, 포커스 표시 제공 |
| NFR-006 | 유지보수성 | 연산 로직과 UI 로직을 분리(MVC 또는 MVVM 등) |
| NFR-007 | 이식성 | 3개 OS에서 동일 기능 동작 보장 |

### 3.3 인터페이스 요구사항

#### 3.3.1 사용자 인터페이스
- 상단: 식 입력/결과 표시(우측 정렬)
- 중앙: 숫자/연산/공학함수 버튼 패널
- 하단 또는 우측: 히스토리 패널, 메모리 상태 표시
- 모드 표시: DEG/RAD 현재 상태를 시각적으로 명확히 제공

#### 3.3.2 소프트웨어 인터페이스
- `CalculatorEngine`: 파싱/계산/오류 처리
- `HistoryManager`: 내역 저장/조회/복원
- `MemoryRegister`: 메모리 값 및 상태 관리

#### 3.3.3 하드웨어 인터페이스
- 표준 키보드, 마우스, 터치 입력장치 지원

## 4. 데이터 및 상태 모델

### 4.1 핵심 데이터
- `current_expression: str`
- `current_result: float | str`
- `angle_mode: DEG | RAD`
- `memory_value: float`
- `history: List[HistoryItem(expression, result, timestamp)]`

### 4.2 상태 전이(요약)
1. 입력 상태 → 계산 실행(`=`)  
2. 계산 성공 시 결과 상태, 실패 시 오류 상태  
3. 오류 상태에서 `C/CE/수정입력`으로 정상 입력 상태 복귀

---

## 5. 오류 처리 요구사항

| 오류 유형 | 조건 | 시스템 동작 |
|---|---|---|
| DivisionByZero | 0으로 나눔 | 계산 중단, 사용자 메시지 출력, 식 유지 |
| DomainError | 예: `sqrt(-1)`, `log(-x)` | 계산 중단, 오류 메시지, 입력 수정 유도 |
| SyntaxError | 괄호 불일치, 연산자 중복 | 실행 차단, 오류 위치 안내 |
| OverflowError | 표현 범위 초과 | 지수표기 또는 오류 메시지 표시 |
