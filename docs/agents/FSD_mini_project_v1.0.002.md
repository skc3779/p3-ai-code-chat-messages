제시해주신 FSD의 구조는 에이전트의 '추론-실행-관찰' 루프를 테스트하기에 매우 훌륭한 골격입니다. 이를 AI 모델이 처리하기 **더 어렵고 까다롭게** 만들려면, 단순한 파일 조작을 넘어 **비결정적 요소(Non-deterministic)**, **의존성 꼬임(Dependency Hell)**, 그리고 **다층적 문맥 추론**을 결합해야 합니다.

LLM의 한계를 시험할 수 있는 심화 버전 3가지를 제안합니다.

---

## 심화 버전 1: 가상 환경 격리 및 런타임 종속성 해결
**목표:** 에이전트가 로컬 환경의 오염을 방지하기 위해 가상 환경(`venv`)을 스스로 구축하고, 버전 충돌이 발생하는 라이브러리 사이에서 최적의 해결책을 찾아내는지 테스트합니다.

* **주요 과제:**
    1.  `venv` 생성 및 활성화 후, `requests==2.25.1`과 특정 보안 패치가 필요한 하위 라이브러리 간의 버전 충돌 상황 부여.
    2.  `requirements.txt`를 생성하되, 일부러 오타나 존재하지 않는 버전을 포함시켜 에이전트의 에러 대응 능력을 확인.
* **[OBSERVE] 테스트 포인트:**
    * `pip install` 실패 시 에러 메시지에서 **Conflict** 원인을 정확히 파악하는가?
    * 가상 환경 내부와 외부의 파이썬 경로(`$ which python` 또는 `$ (Get-Command python).Source`) 차이를 인식하는가?
* **어려운 점:** 에이전트는 종종 가상 환경을 '활성화'만 하고 실제 명령은 시스템 전역 파이썬으로 실행하는 실수를 범합니다. 이를 잡아내는지 보는 것이 핵심입니다.

---

## 심화 버전 2: 다중 파일 리팩토링 및 인터페이스 정합성
**목표:** 하나의 파일이 아닌, 상호 의존적인 여러 파일(Module A, B, C)이 얽힌 상태에서 인터페이스(함수 시그니처) 변경 시 발생하는 연쇄 효과를 관리할 수 있는지 테스트합니다.

* **주요 과제:**
    1.  `core.py`, `api.py`, `main.py` 세 파일을 생성.
    2.  `core.py`에 있는 함수의 파라미터 개수를 변경(예: `def save(data)` -> `def save(data, mode='db')`).
    3.  에이전트에게 "시스템 전체의 안정성을 유지하며 기능을 업그레이드하라"는 모호한 명령 하달.
* **[OBSERVE] 테스트 포인트:**
    * `core.py`만 수정하고 끝내는가, 아니면 이를 참조하는 `api.py`와 `main.py`까지 찾아내어 `[ACT — Patch]`를 수행하는가?
    * 전체 테스트 스크립트를 작성하여 **Regression Test(회귀 테스트)**를 스스로 수행하고 `[OBSERVE]`에 기록하는가?
* **어려운 점:** 컨텍스트 윈도우 내에서 파일 간의 '연결 고리'를 놓치기 쉽습니다.

---

## 심화 버전 3: 비정형 데이터 파싱 및 고난도 디버깅 (Race Condition)
**목표:** 정형화되지 않은 로그 데이터나 복잡한 재귀 함수에서의 논리 오류를 추적하고, 실행 환경의 일시적 오류(Transient Error)에 대응하는 능력을 테스트합니다.

* **주요 과제:**
    1.  비동기 처리(`asyncio`) 혹은 멀티스레딩이 포함된 코드를 작성하게 함.
    2.  의도적으로 **Race Condition**이 발생하여 결과값이 간헐적으로 틀리게 나오는 상황 연출.
    3.  매우 긴 시스템 로그 파일(100줄 이상)에서 특정 패턴의 에러를 찾아내어 리포트하게 함.
* **[OBSERVE] 테스트 포인트:**
    * 단 한 번의 실행 결과만 보고 "성공"이라 판단하는가, 아니면 반복 실행을 통해 **일관성(Consistency)**을 검증하는가?
    * `[REASON]` 단계에서 코드의 논리적 흐름(Race Condition 가능성)을 이론적으로 짚어내는가?
* **어려운 점:** AI는 보통 코드가 '실행'만 되면 성공으로 간주하는 경향이 있습니다. 간헐적 오류를 잡기 위한 `[OBSERVE]`의 집요함을 테스트할 수 있습니다.
