# Functional Specification Document (FSD)
## Project: Big Calculator
## Version: v1.0.030

### 1. 개요 (Overview)
본 문서는 Big Calculator 프로젝트의 v1.0.030 버전에 대한 기능 명세서입니다. 기존 v1.0.010 및 v1.0.020에서 구현된 기본 사칙연산 및 무제한 자릿수(BigInt) 연산 기능에 더하여, 공학용 계산 기능과 사용자 편의성을 위한 히스토리 기능을 추가하는 것을 목표로 합니다.

### 2. 기능 요구사항 (Functional Requirements)

#### 2.1 기존 기능 유지 (v1.0.010, v1.0.020)
- **기본 사칙연산**: 덧셈, 뺄셈, 곱셈, 나눗셈
- **큰 수 처리**: 메모리가 허용하는 한 무제한 자릿수의 정수 및 소수점 연산 지원
- **메모리 기능**: M+, M-, MR, MC 지원

#### 2.2 신규 기능 (v1.0.030)
- **공학용 함수 지원**: 
  - 삼각함수 (sin, cos, tan) 및 역삼각함수
  - 로그함수 (log, ln)
  - 지수함수 (e^x, x^y)
  - 제곱근 (sqrt)
- **계산 히스토리 기능**:
  - 최근 50개의 계산식 및 결과 저장
  - 히스토리 내역 클릭 시 현재 입력창으로 불러오기 기능
  - 히스토리 초기화 기능

### 3. 비기능 요구사항 (Non-Functional Requirements)
- **성능**: 10,000자리 이상의 연산 시에도 1초 이내에 결과를 반환해야 함.
- **안정성**: 잘못된 수식 입력 시 앱이 종료되지 않고 명확한 에러 메시지를 표시해야 함.

### 4. 사용자 인터페이스 (UI/UX)
- 기존 표준 계산기 모드와 공학용 계산기 모드를 전환할 수 있는 토글 버튼 추가.
- 우측 또는 하단에 슬라이드 패널 형태로 히스토리 뷰 제공.

### 5. 예외 처리 (Exception Handling)
- 0으로 나누기 시도 시 "0으로 나눌 수 없습니다." 에러 출력.
- 음수의 제곱근 계산 시 "유효하지 않은 입력입니다." 에러 출력 (복소수 미지원).

## 6. 가이드 작성

제품 설명, 간단한 기능소개, 설치 및 사용 방법에 대한 가이드 문서 작성.


## 7. 테스트

1. 설치 및 실행
   - Windows/Mac/Linux에서 모두 설치 및 실행이 잘 되는지 확인
   - 설치 시 Python 가상환경을 사용하는 경우와 전역(Global)으로 설치하는 경우 모두 확인
2. 기본 기능 테스트
   - 기본 사칙연산(+, -, *, /)이 정확한 결과로 동작하는지 확인
   - 소수점 입력 및 계산이 잘 동작하는지 확인
   - 0으로 나누기 등 오류 상황에서 적절한 오류 메시지를 표시하는지 확인
3. 공학 기능 테스트
   - 삼각함수(sin, cos, tan, asin, acos, atan)가 정확한 결과로 동작하는지 확인
   - 로그 및 지수 함수(log10, ln, 10^x, e^x, x^y)가 정확한 결과로 동작하는지 확인
   - 제곱근(sqrt) 및 팩토리얼(n!)이 정확한 결과로 동작하는지 확인
   - DEG/RAD 각도 모드 전환이 올바르게 동작하는지 확인
4. 메모리 기능 테스트
   - MS, MR, M+, M- 메모리 기능이 정확하게 동작하는지 확인
5. UI/UX 테스트
   - 버튼 크기가 충분히 큰지 확인
   - 디지털 화면이 선명하게 잘 보이는지 확인
   - 키보드 입력이 잘 동작하는지 확인
   - Undo/Redo 기능이 정확하게 동작하는지 확인
   - 계산 내역이 정확하게 표시되고 스크롤이 잘 동작하는지 확인
6. 성능 테스트
   - 연속 100회 입력 후 반응 속도 측정
   - 복잡한 계산(예: sin(123) * log(456) / 789)의 속도 측정
