- **대상 환경:** Python 3.10 이상
- **작성일:** 2026-09-06

## 1. 개요 (Overview)

### 1.1 프로젝트 목적
본 문서는 Python 3 기반의 데스크톱 애플리케이션인 **Mini Calculator(단순 계산기)**의 최종 기능 명세서(FSD)입니다.  
학생, 사무직 등 일반 데스크톱 사용자가 일상적인 사칙연산을 빠르고 직관적으로 수행할 수 있도록, **대형 디지털 디스플레이**, **시인성이 뛰어난 큰 버튼**, **계산 내역(History) 기록 및 복원(Undo)** 기능을 제공하는 것을 목표로 합니다.

### 1.2 핵심 범위
- 기본 사칙연산(`+`, `-`, `*`, `/`) 및 실수(소수점 `.`) 연산
- 대형 디지털 디스플레이 (최소 높이 200px, 폰트 24pt 이상)
- 큰 버튼 그리드 (최소 60px × 60px) 및 마우스/터치/키보드 입력 지원
- 연산 기록(History) 리스트 표시 및 선택 복원
- 직전 상태 되돌리기(Undo) 및 전체/부분 초기화(C, CE, Backspace)
- 0으로 나누기 등 연산 예외 처리 및 안정적인 안내
- 다국어(i18n) 확장을 고려한 UI 문자열 리소스 분리

## 2. 공통 준수 사항 및 프로젝트 구조 규격

본 프로젝트는 유지보수성, 확장성, 테스트 용이성을 극대화하기 위해 다음 공통 규격을 엄격히 준수합니다.

### 2.1 공통 준수 규격 5대 원칙
1. **README.md 문서화**: 프로젝트 개요, 아키텍처 설명, 설치 및 가상환경 구성, 빌드/실행 방법, 사용 설명서를 포함하는 상세 가이드를 제공한다.
2. **requirements.txt 라이브러리 관리**: 애플리케이션 실행 및 테스트에 필요한 모든 외부 의존성을 `requirements.txt`에 명시하고 버전을 고정 관리한다.
3. **src 소스 코드 디렉터리 분리**: 모든 실행 코드는 `src/` 디렉터리 하위에 작성하며, 엔트리포인트는 `src/main.py`로 구성한다.
4. **코드 분할(Code Splitting) 및 관심사의 분리(SoC)**:
   - UI(View), 비즈니스 로직(Model), 사용자 상호작용 및 이벤트 제어(Controller)를 철저히 분리(MVC 패턴)한다.
   - 단일 파일에 기능이 집중되지 않도록 모듈화하며, 단일 클래스/함수는 200줄 이내로 제한한다.
5. **tests 테스트 코드 디렉터리 분리**: 모든 단위 테스트 및 통합 테스트 코드는 `tests/` 디렉터리에 작성하며, Python 표준 `unittest` 또는 `pytest`를 지원한다.

## 5. 아키텍처 및 모듈 상세 설계 (SoC & Code Splitting)

### 5.1 아키텍처 흐름도 (MVC Pattern)

```
[사용자 입력 (키보드 / 마우스 터치)]
             │
             ▼
┌─────────────────────────────────────────┐
│        CalculatorView (UI 계층)         │
│  - DisplayPanel (대형 화면)             │
│  - KeypadPanel (대형 버튼 그리드)        │
│  - HistoryPanel (계산 기록 패널)        │
└────────────────────┬────────────────────┘
                     │ (UI 이벤트 전달)
                     ▼
┌─────────────────────────────────────────┐
│     CalculatorController (제어 계층)    │
│  - 입력값 검증 (Validator 호출)          │
│  - Model 상태 갱신 명령                  │
│  - View 렌더링 갱신 지시                 │
└──────────┬───────────────────▲──────────┘
           │ (상태 갱신)        │ (데이터 통보)
           ▼                   │
┌─────────────────────────────────────────┐
│        CalculatorModel (데이터/로직 계층) │
│  - 현재 식(expression), 결과(result) 관리│
│  - 사칙연산 계산 엔진                   │
│  - HistoryManager (기록 및 Undo 스택)   │
└─────────────────────────────────────────┘
```

### 5.2 모듈별 역할 및 책임 분담

1. **`src/models/calculator_model.py`**
   - 사칙연산 수식 평가 (`evaluate(expression: str) -> str`)
   - 0으로 나누기 및 비정상 수식 연산 예외 포착
   - 현재 표시할 식(`current_expression`)과 결과(`current_result`) 보관

2. **`src/models/history_manager.py`**
   - 연산 히스토리 리스트(`List[Dict[str, str]]`) 관리
   - Undo 기능 제공을 위한 이전 상태 스택(`undo_stack`) 푸시/팝 처리
   - 최대 보관 개수(50개) 초과 시 FIFO 방식으로 제거

3. **`src/views/main_view.py` 및 하위 컴포넌트**
   - Tkinter 기반 윈도우 생성 및 반응형 크기 조절
   - `DisplayPanel`: 현재 식과 결과값을 분리된 라벨로 고해상도 표시
   - `KeypadPanel`: 4×5 그리드 버튼 배치 및 키 바인딩
   - `HistoryPanel`: 스크롤 가능한 리스트박스 및 Undo 버튼 배치

4. **`src/controllers/calculator_controller.py`**
   - 버튼 클릭 및 키보드 입력 이벤트를 수신하여 `Validator`를 통한 입력 유효성 확인
   - 연산 요청 시 `CalculatorModel`에 전달하고 결과값을 `DisplayPanel`과 `HistoryPanel`에 반영

5. **`src/utils/validator.py`**
   - 연산자 중복 입력 방지 (`1++2` 차단)
   - 소수점 중복 입력 방지 (`1.2.3` 차단)
   - 선행 0(Leading zeros) 처리

## 6. 예외 처리 및 에러 핸들링 규격

| 예외 상황 | 발생 원인 | 처리 방식 및 UI 출력 메시지 | 상태 복구 방안 |
|---|---|---|---|
| **ZeroDivisionError** | 숫자를 0으로 나누는 연산 시도 (`5 / 0`) | 디스플레이에 `"오류: 0으로 나눌 수 없습니다."` 경고 표시 | `C` 버튼 또는 새로운 숫자 입력 시 정상 상태로 리셋 |
| **SyntaxError** | 잘못된 연산자 위치 (`5 + * 2` 또는 `3 + =`) | 디스플레이에 `"잘못된 수식입니다."` 표시 및 연산 보류 | 마지막 문자 삭제(`Backspace`) 후 정상 입력 유도 |
| **ValueOverflow** | Python 부동소수점 한계 초과 연산 | `"연산 범위를 초과했습니다."` 표시 | `C` 버튼으로 초기화 |
| **EmptyExpression** | 입력 없이 `=` 클릭 | 무반응 (에러 미발생) | 사용자 입력 대기 |

## 7. 테스트 명세 및 검증 계획 (`tests/`)

### 7.1 단위 테스트 (Unit Test) 항목

1. **`tests/test_calculator_model.py`**
   - 정수 및 소수 덧셈, 뺄셈, 곱셈, 나눗셈 정밀도 검증
   - 연산자 우선순위(`2 + 3 * 4 = 14`) 정확도 검증
   - 0으로 나누기 시도 시 `ZeroDivisionError` 예외 발생 여부 확인

2. **`tests/test_history_manager.py`**
   - 계산 완료 시 히스토리에 정상 적재되는지 검증
   - `undo()` 호출 시 직전 계산 상태로 정확히 되돌아가는지 검증
   - 50개 초과 적재 시 가장 오래된 항목이 제거되는지 검증

3. **`tests/test_validator.py`**
   - 연속된 연산자 입력 필터링 테스트
   - 소수점 중복 입력 필터링 테스트

4. **`tests/test_integration.py`**
   - Controller를 통한 전체 입력-연산-뷰 갱신 통합 흐름 검증

### 7.2 수용 테스트(Acceptance Test) 시나리오

| TC ID | 테스트 시나리오 | 수행 절차 | 기대 결과 |
|---|---|---|---|
| **TC-MINI-01** | 기본 사칙연산 | `12 + 34 =` 입력 | 디스플레이에 `46` 출력 및 내역에 `12 + 34 = 46` 추가 |

## 8. 산출물 및 문서화 규격

### 8.1 README.md 작성 요구사항
프로젝트 루트에 위치하는 `README.md`는 다음 항목을 빠짐없이 포함해야 합니다.
1. **프로젝트 개요**: Mini Calculator의 목적과 특징 (큰 화면, 큰 버튼, Undo)
2. **주요 기능 목록**: 사칙연산, 대형 디스플레이, 히스토리, Undo, 단축키
3. **아키텍처 및 폴더 구조**: MVC 구조, Code Splitting 및 SoC 설명
4. **설치 및 환경 구성 가이드**: Python 3.10+ 가상환경(`venv`) 생성 및 활성화
5. **의존성 설치**: `pip install -r requirements.txt`
6. **실행 방법**: `python src/main.py`
7. **테스트 실행 방법**: `python -m unittest discover -s tests`
8. **키보드 단축키 안내 표**

### 8.2 requirements.txt 규격
- GUI 프레임워크: Tkinter (Python 표준 라이브러리 내장 사용 권장)
- 테스트 도구 및 린터:
  ```
  pytest>=7.4.0
  flake8>=6.0.0
  ```
