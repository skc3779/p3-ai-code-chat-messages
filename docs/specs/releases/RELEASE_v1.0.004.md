## 주요 변경 사항
- **터미널/Shell 통합:** 시스템 명령어를 실행할 수 있는 `TerminalExecutor` 기능을 추가하여 앱 내에서 직접 쉘 명령어를 실행할 수 있게 되었습니다. 
- **신규 명령어 추가:**
  - `/shell <command>`: 안전한 명령어만 실행 허용 (안전 모드)
  - `/shell! <command>`: 위험 명령어를 포함한 모든 명령어 허용 (위험 모드, 실행 전 확인)
