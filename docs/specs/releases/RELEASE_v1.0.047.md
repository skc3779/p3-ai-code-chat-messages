## 개요

TUI(Terminal User Interface)의 대대적인 진화! AI 어시스턴트 코드 베이스에 `prompt_toolkit`의 고급 레이아웃 시스템을 도입하여, **Google Gemini CLI 스타일의 전체 화면 인라인 명렁어 제안(Suggestion) 기능 및 상태 표시줄**을 성공적으로 이식했습니다.

더 이상 명령어 목록을 외울 필요도, `/help`를 일일이 타이핑할 필요도 없습니다.

---

## 신규 기능

### 1. 인라인 슬래시 명령어 제안 (Slash Command Suggestions)

프롬프트 커서에서 `/` 기호 하나만 입력하면 즉시 현재 터미널 하단에 사용할 수 있는 모든 명령어 목록이 우아하게 나타납니다.

- **실시간 비동기 필터링**: `/s` 타이핑 시 실시간으로 `save`, `stream`, `shell` 등 해당되는 명령어만 슬림하게 좁혀집니다.
- **키보드 네비게이션**: ↑↓ 위아래 방향키로 명령어를 직관적으로 고르고 `Tab`이나 `Enter`를 통해 자동 완성합니다.
- **Gemini 고유 플랫 스타일**: 둔탁한 팝업 박스를 벗어나, 콘솔 폭을 전체로 활용한 테두리 없는(Flat) 세련된 디자인.
- **가독성 증가**: `/save` 대신 `save` 형태의 볼드(#e0e0e0) 폰트 출력과 어두운 회색조의 메타 설명으로 몰입감을 높입니다.

### 2. 반응형 3영역 하단 상태 바 (Bottom Toolbar)

단순했던 TUI 창 바닥에 Gemini CLI 스타일의 3단 분열(좌/중/우) 고정형 정보 표시줄을 추가했습니다.
- **좌측**: 현재 작업 공간(Workspace) 경로 실시간 노출. 너무 길 경우 중간을 말줄임표(`...`)로 세련되게 축약.
- **중앙**: 스트리밍 통신 모드 상태(`streaming` / `nostream`) 표시
- **우측**: 현재 로드된 LLM 모델 정보 (`/model gemini-3.0-flash` 등) 노출

### 3. 페이지네이션 및 스마트 스크롤 UI

명령어 목록이 터미널 사이즈를 넘어설 경우를 위한 스마트 뷰포트를 구축했습니다.
- 스크롤 가능 여부를 보여주는 시각적 인디케이터(`▼`, `▲`) 제공
- 현재 스크롤 위치를 가늠할 수 있는 페이지네이션 `(1/29)` 텍스트 창 좌측 하단 배치

## 실행/확인 가이드

이 버전 이후부터는 구동 즉시 새로운 `>` 기호 스탠스와 함께 스마트한 경험이 시작됩니다:

```bash
python gemini-ai-chat-code01.py
```
프롬프트가 열리면 `/ ` 를 눌러 새로운 명령어 창의 작동을 확인해보세요!
