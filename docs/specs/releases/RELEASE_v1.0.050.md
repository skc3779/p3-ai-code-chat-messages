# RELEASE v1.0.050

## 릴리즈 정보
- **버전:** v1.0.050
- **배포일:** 2026-02-26

## 주요 변경 사항
- **멀티라인 텍스트 편집기 도입:** `prompt_toolkit` 라이브러리를 활용하여 콘솔에서 직접 여러 줄의 텍스트를 손쉽게 편집하고 입력할 수 있는 기능이 추가되었습니다. 커서 이동, 텍스트 수정, `Meta+Enter` 전송 등을 지원합니다.
- **관련 문서:** `FSD_v1.0.050_multiline-text-editing.md`

## 버그 수정
- **멀티라인 입력 종료 관련 오류 수정:** `/end` 명령어 등 특정 조건에서 멀티라인 입력이 비정상 종료되던 이슈를 해결했습니다.
- **관련 문서:** `BUG_v1.0.050_multiline-end-command.md`
